# the steps built so far and counts the rest as pending.

# commented out with a dated line saying why, and its correction is added
# below it, so the record shows what was believed before the run.

# Format:   steps | kind | arguments | source
# Steps:    N binds from step N onward; N-M binds from step N to step M.
#           The grammar is one file, ProppEBNF46.txt, that every step
#           changes, with a git tag per step. A test a later step is
#           planned to break is given its closing step when it is frozen.
